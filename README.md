# DeepHelp

The default branch is a browser page titled NexusAI Web Validator for Gemini text/image requests. The separate Started-building-scraper-app branch contains a Python/React scraping and analytics experiment. They are distinct implementations, not a verified integrated full-stack application.

## Current state

Browser Gemini API validator and separate scraper experiment. Documentation describes inspected source and configuration; no runtime, device, player-build, deployment, or rights certification is implied. The default branch is `development`.

## Start here

Read [development instructions](docs/development.md) for the supported opening/inspection route and [known issues](docs/known-issues.md) before attempting execution. Validate the local UI without live keys; separately authorize credential handling and a live API or scraper integration pass.

## Important implementation and value

A compact request/retry/response/export example plus historical analytics/scraper experiments with clear integration gaps.
