# Provenance and rights

The validator page and scraper/analytics glue are project implementation; Google APIs, JSZip, Flask, React, Playwright, and OAuth libraries are third-party services/tooling. User inputs, generated outputs, and scraped content have separate applicable terms. Tracked credential-related filenames and browser profiles are security boundaries, not reusable authentication. No repository-wide rights grant was established.

## Review before reuse

Record the source/author, applicable license or contract, attribution requirements, modification history, redistribution terms, and intended use for each imported asset/dependency or data collection. A missing license is not permission. Do not invent company/client ownership from repository names. Preserve original third-party notices and separately verify commercial use.

No license was added or changed during this documentation phase. Rights review, consent, and external-service ownership remain separate gates.
